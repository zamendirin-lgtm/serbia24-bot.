# 🇷🇸 Сербия 24 — бесплатный автоматический новостной бот

Бот проверяет RSS-анонсы сербских СМИ RTS, N1, Danas и B92, отбирает свежие новости, переводит заголовки и короткие анонсы на русский язык и публикует их в вашем Telegram-канале **со ссылкой на первоисточник**.

## Подключение Telegram — два секрета

**Токен бота был раскрыт в переписке. Перед запуском обязательно отзовите его через @BotFather командой `/revoke` и используйте новый. Ни в код, ни в README его вставлять не нужно.**

1. В канале Telegram откройте «Управление каналом → Администраторы → Добавить администратора». Добавьте своего бота и включите разрешение **«Публиковать сообщения»**.
2. В этом GitHub-репозитории откройте **Settings → Secrets and variables → Actions → New repository secret**.
3. Создайте секрет **`TELEGRAM_BOT_TOKEN`**. Значение — *новый* токен, выданный BotFather.
4. Создайте секрет **`TELEGRAM_CHANNEL`**. Значение — публичный адрес канала, например `@serbia24news` (это пример — укажите свой настоящий адрес).
5. Откройте вкладку **Actions → Serbia24 automatic news → Run workflow → Run workflow** и проверьте результат. При первом запуске бот может отправить до двух свежих новостей.

### Автоматическое расписание

Файл `.github/workflows/news.yml` запускает бота примерно каждые 30 минут (GitHub может задерживать запуски). По умолчанию **до 2 публикаций за запуск и 10 в сутки**, время суток — Europe/Belgrade.

История опубликованных ссылок и похожих заголовков сохраняется в `data/seen.json` для предотвращения повторов. Для этого workflow использует `contents: write`. Если GitHub откажет в сохранении истории, разрешите **Settings → Actions → General → Workflow permissions → Read and write permissions**, если такая настройка доступна.

## Источники и качество

- [RTS](https://www.rts.rs/vesti/rss.html)
- [N1](https://n1info.rs/feed/)
- [Danas](https://www.danas.rs/feed/)
- [B92](https://www.b92.net/rss/b92/info)

Перевод идёт через проверенный открытый endpoint Google Translate; при ошибке бот переключается на MyMemory (анонимный лимит **5000 символов в день**). Оба варианта работают **без платного API**, но их доступность и стабильность не гарантируются. Если перевод не удаётся, новость не публикуется. Это не полноценная автоматическая редакция и не надёжная проверка фактов: источник может ошибаться, а машинный перевод и фильтр по ключевым словам способны исказить смысл или пропустить важную новость.

Новости не старше восьми часов, только короткие анонсы (полный текст чужих статей и фотографии бот не копирует). Записываются заголовки и ссылки опубликованных материалов, но не персональные токены.

## Проверка перед запуском

Вкладка **Actions → Serbia24 code tests** показывает автоматические тесты, которые запускаются при изменении кода.

Локально:

```bash
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
DRY_RUN=1 python bot.py
```

`DRY_RUN=1` проверяет получение лент и перевод, но не публикует сообщения и не сохраняет историю.

## Что бесплатно

GitHub Actions для обычных GitHub-hosted runners **в публичном репозитории**, Telegram Bot API и использование неофициального бесплатного переводчика. Платный сервер или подписка на ИИ не требуются, но возможны ограничения частоты переводов и задержки GitHub Actions.

Если секреты ещё не добавлены, автоматический workflow завершится ошибкой конфигурации и не опубликует сообщения — это ожидаемо. Никогда не делайте токен публичным.
