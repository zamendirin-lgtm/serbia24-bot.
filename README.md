# 🇷🇸 Сербия 24 — бесплатный автоматический новостной бот

Бот проверяет RSS-анонсы сербских СМИ RTS, N1, Danas и B92, отбирает свежие новости, переводит заголовки и короткие анонсы на русский язык и публикует их в вашем Telegram-канале **со ссылкой на первоисточник**.

## Как отбираются интересные новости

Во время обкатки бот предпочитает **практические новости для жителей Сербии**, а не просто самые свежие статьи. Главные темы: конкретные цены на продукты и топливо, тарифы, счета, аренда, зарплаты и пенсии, налоги, банковские новости, документы, транспорт, школы, медицина и значимые законодательные изменения. Отдельно учитываются предупреждения о безопасности.

- Цена должна быть подтверждена первоисточником: **сумма, валюта, единица товара или услуги, срок действия**. Если в статье приведено сравнение со старой ценой, его нужно раскрыть.
- Сведения о сумме ущерба в криминальной новости **не считаются потребительской ценой**.
- Спортивные анонсы, рядовые семинары и новости без практической ценности получают низкий приоритет. При отсутствии достаточно полезной статьи бот лучше пропустит очередной слот, чем заполнит ленту.
- Учитывается свежесть новости, сохраняется проверка достоверности, языка, смысловых дублей, фотографий и ночное ограничение публикаций.
- Бот по-прежнему публикует только **одну** качественную новость за запуск, с паузой **не менее 90 минут между публикациями**, в период 08:00–22:00 по Белграду. Проверки RSS продолжаются примерно каждые 15 минут.

## Стиль публикаций

- **Фотография из RSS или OG-метаданных исходной статьи** отправляется отдельным Telegram-фото с русской подписью. Так больше не показываются английские/сербские заголовки карточки ссылки. Если подходящей фотографии нет, она повторяется или сервер не принимает её, бот **формирует горизонтальную фирменную картинку из аватарки Telegram-канала** и прикрепляет её вместо исходной фотографии. Без изображения пост не публикуется.
- Эмодзи по теме новости, **цепляющий, но точный заголовок**, затем два-три коротких абзаца по фактам исходной статьи (не только RSS). Первый абзац раскрывает обещание заголовка.
- Под текстом только кликабельная ссылка на первоисточник. Хештеги и название канала в конце поста не добавляются.
- Веб-превью ссылки отключено. Изображение отправляется с оригинального адреса издателя. Важное ограничение: текст, уже напечатанный **внутри самой фотографии**, автоматически не удаляется; перед перепубликацией чужих фото учитывайте права правообладателя.
- Фильтр требует прямой связи с Сербией, отклоняет иностранные новости без местной привязки (например, заявления Трампа об Иране) и новости исключительно о событиях в Косове без непосредственного участия сербских госорганов. Это редакционная политика канала, не оценка политического статуса территорий.
- Из RSS-анонсов берутся максимум два законченных информационных предложения; рекламные вопросы и обрывки не публикуются. Для спорных событий требуется сверка источников.
- Повторные и шаблонные фотографии блокируются по URL и визуальному отпечатку за 60 дней. Если подходящего фото нет, используется брендированная обложка с аватаркой канала; при сбое отправки обложки новость пропускается. В частности, одинаковые YouTube-вставки из RSS Danas не считаются фотографиями новости.


## Подключение Telegram — осталось добавить один секрет

Публичный адрес канала уже установлен в рабочем процессе: **[@serbia24live](https://t.me/serbia24live)**. Отдельный секрет `TELEGRAM_CHANNEL` больше не требуется.

**Токен бота был опубликован в чате. Для безопасности отзовите его в @BotFather командой `/revoke` и получите новый. Никогда не добавляйте токен в исходный код и не присылайте его в переписку.**

1. Убедитесь, что бот добавлен администратором канала `@serbia24live` с правом **«Публиковать сообщения»**.
2. Откройте в GitHub **Settings → Secrets and variables → Actions → New repository secret**.
3. В поле Name укажите `TELEGRAM_BOT_TOKEN`; в поле Secret вставьте новый токен от BotFather. Сохраните.
4. Вкладка **Actions → Serbia24 automatic news → Run workflow → Run workflow** выполнит первый тест публикации. Никаких токенов в логах не печатается.
5. В дальнейшем проверка выполняется по расписанию. При отсутствии токена запуск безопасно пропускает публикацию.

### Автоматическое расписание

Файл `.github/workflows/news.yml` запускает проверку примерно каждые 15 минут **в дневные часы** (GitHub может задерживать запуски). **Тихие часы: с 22:00 до 08:00 по Белграду, без публикаций**; правило выполняется в самом боте и учитывает зимнее/летнее время, включая ручные запуски. **Окончательный режим: максимум 1 публикация за запуск и 10 за календарный день, пауза не менее 90 минут между публикациями.** Если подходящих новостей нет, пост пропускается.

История опубликованных ссылок, заголовков и кратких анонсов сохраняется в `data/seen.json` **за последние 60 дней**. Бот проверяет повторные ссылки, близкие формулировки, порядок слов и совпадение ключевых слов события **между разными СМИ** (в том числе кириллицей и латиницей). Новые цены/числа, отрицания и противоположные события не должны автоматически считаться дублями. Это бесплатная эвристика, не стопроцентная семантическая проверка: радикально перефразированный повтор иногда может пройти, а близкие сообщения — быть отфильтрованы. Дополнительно действуют тестовые лимиты — 1 пост за запуск и до 10 в сутки. Для этого workflow использует `contents: write`. Если GitHub откажет в сохранении истории, разрешите **Settings → Actions → General → Workflow permissions → Read and write permissions**, если такая настройка доступна.

## Редакционное качество — главный критерий тестирования

- Вместо короткого RSS-анонса бот пытается прочитать **основной текст статьи** на сайте издателя.
- В пост берутся **2–3 связных абзаца**, содержащие факты, обстоятельства и важные подробности. Каждый абзац должен развивать заголовок.
- Рекламные вопросы, ссылки на другие новости, обрывки предложений и сообщения без достаточного содержания отбрасываются.
- Если невозможно получить понятное изложение, бот **пропускает статью**, а не публикует один заголовок.
- Объём ограничен Telegram-подписью к фото (1024 символа). Ссылка на оригинал остаётся для подробностей.
- **Новая проверка:** после перевода отдельный редакторский модуль `editorial.py` удаляет повторяющиеся абзацы, тире перед предложениями и пропускает слишком короткие либо бессвязные тексты.
- **Необязательный ИИ-редактор:** чтобы переформулировать черновой перевод естественным русским языком, можно подключить бесплатный тариф Google Gemini 2.5 Flash-Lite. Без его ключа действует ограниченная алгоритмическая редактура — она не может полноценно переписать сложные цитаты.
- При подключении ИИ он получает заголовок и фактические абзацы сербского источника вместе с черновым переводом и возвращает 2–3 русских абзаца. Проверяются длина, повторы, посторонние цифры, рекламные ссылки и обрывы. Если ИИ недоступен или возвращает сомнительный текст, **публикация пропускается**.
- ИИ не гарантирует безошибочной проверки фактов: продолжаем смотреть реальные посты, особенно о политике, суде и происшествиях.
- На этапе обкатки лимит установлен **не более 10 новостей в сутки**, проверка источников примерно каждые 15 минут, публикации только **08:00–22:00 по Белграду**.

## Бесплатная ИИ-редактура: интригующий заголовок, ясное содержание

Основной рекомендованный вариант — **GroqCloud Free с моделью `openai/gpt-oss-120b`**. Он работает с API и умеет возвращать JSON. На опубликованном бесплатном плане указаны ориентиры до 1000 запросов/день и 200 000 токенов/день для GPT-OSS 120B, но фактические квоты могут отличаться. Никаких платежей без отдельного перехода на платный тариф.

Подключение Groq (один раз):

1. Откройте [GroqCloud Console](https://console.groq.com/keys), бесплатно зарегистрируйтесь и создайте API key.
2. Откройте [секреты GitHub](https://github.com/zamendirin-lgtm/serbia24-bot./settings/secrets/actions) → **New repository secret**.
3. Название: `GROQ_API_KEY`; значение: ключ Groq. **Не отправляйте ключ в чат и не пишите его в коде**.
4. При наличии ключа бот сам выбирает редактор Groq и модель `openai/gpt-oss-120b`. Обслуживание и расписание менять не нужно.

Редакционная инструкция: **заголовок интригует, но не вводит в заблуждение; первый абзац раскрывает главное обещание заголовка, следующий добавляет факты и контекст**. Без «шок», «вы не поверите», кликбейта и придуманных цифр. ИИ получает только отобранные факты и черновой перевод; сомнительный результат не публикуется.

Резервный вариант — [Google AI Studio](https://aistudio.google.com/apikey): ключ в секрете `GEMINI_API_KEY` (также поддерживается `GOOGLE_API_KEY`), модель **`gemini-3.5-flash-lite`** на бесплатном тарифе при наличии подходящей квоты. **Приоритет:** Groq → Gemini при сбое/неудачной проверке текста Groq → базовая автоматическая редактура, только если ни один API-ключ не задан. Если настроенный ИИ недоступен, а резервный тоже не отвечает, сомнительная публикация пропускается. Ключи должны быть именно в разделе GitHub `Secrets`, не в открытом коде и не в `Variables`. На 12 ноября 2026 года живой тест обнаружил Groq, но **не обнаружил Gemini ни под одним из двух поддерживаемых имён**; для резервной модели нужно проверить название секрета. Для непрерывного высокого качества контроль реальных постов остаётся необходим.

Ссылки на условия и лимиты: [Groq rate limits](https://console.groq.com/docs/rate-limits), [Google Gemini free pricing](https://ai.google.dev/gemini-api/docs/pricing), [OpenRouter free quota](https://openrouter.ai/pricing). Возможности и квоты провайдеры могут менять.


## Источники и качество

- [RTS](https://www.rts.rs/vesti/rss.html)
- [N1](https://n1info.rs/feed/)
- [Danas](https://www.danas.rs/feed/)
- [B92](https://www.b92.net/rss/b92/info)

Перевод идёт через проверенный открытый endpoint Google Translate; при ошибке бот переключается на MyMemory (анонимный лимит **5000 символов в день**). Оба варианта работают **без платного API**, но их доступность и стабильность не гарантируются. Если перевод не удаётся, новость не публикуется. Это не полноценная автоматическая редакция и не надёжная проверка фактов: источник может ошибаться, а машинный перевод и фильтр по ключевым словам способны исказить смысл или пропустить важную новость.

Новости не старше восьми часов, только короткие анонсы (полный текст чужих статей бот не копирует). Издательские фотографии передаются Telegram с исходного URL. Записываются заголовки, ссылки и отпечатки уже использованных фото, но не персональные токены.

## Проверка перед запуском

Вкладка **Actions → Serbia24 code tests** показывает автоматические тесты, которые запускаются при изменении кода.

Локально:

```bash
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
DRY_RUN=1 python bot.py
```

`DRY_RUN=1` проверяет получение лент и перевод **только в дневные часы**; ночью тихие часы останавливают даже сухой запуск. Он не публикует сообщения и не сохраняет историю.

## Что бесплатно

GitHub Actions для обычных GitHub-hosted runners **в публичном репозитории**, Telegram Bot API и использование неофициального бесплатного переводчика. Платный сервер или подписка на ИИ не требуются, но возможны ограничения частоты переводов и задержки GitHub Actions.

Если секреты ещё не добавлены, автоматический workflow завершится ошибкой конфигурации и не опубликует сообщения — это ожидаемо. Никогда не делайте токен публичным.
