# 🇷🇸 Сербия 24 | Афиша — концерты, выставки и события Сербии

Отдельный Telegram-бот в существующем репозитории новостного бота. Он не изменяет news.yml или property_bot.py.

## Концепция
- Бесплатные и платные события: выставки, фестивали, концерты, театры, городские праздники, ярмарки и детские мероприятия.
- Карточка на русском: название, точная дата/время (если опубликованы), город, площадка, короткое описание, стоимость в динарах/евро, отдельные ссылки на подробности и на продажу билетов (если ссылка точно известна).
- Цена строго по источнику: если платный вход подтверждён и есть цена, указывается сумма или «от» при наличии нижней границы; при явно бесплатном входе — «Бесплатно»; если цену установить нельзя — «Цена: не указана», без домыслов.
- Изображение: если имеется официальное промоизображение из разрешённого источника, бот может показать его через sendPhoto; если нет, отправляет текст без чужого предпросмотра. Для источников без права на изображения фото не копируются.
- Не публикуются события с некорректной или прошедшей датой. Выставки с периодом работы могут публиковаться, пока они идут. Только один пост за запуск, защита от повторов.
- При отсутствии убедительных событий бот пропускает публикацию, а не выдумывает программу или цену.

## Источники первой версии
- Официальный календарь Туристической организации Нови-Сада: https://novisad.travel/en/kalendar-dogadjaja/kategorija/calendar-of-events/list/
- Читается только официальная страница списка и несколько страниц событий, если это разрешено robots.txt. На странице события требуется структурированная разметка schema.org/Event с датой. Нет обхода блокировок/капч и массового копирования чужих описаний.
- **Белград**: публичный городской календарь RUN BGD (https://www.runbgd.com/whats-on); дату, место, цену и билеты читаем из карточек. Отдельную ссылку на билеты добавляем, только когда она действительно существует.
- **Суботица и окрестности**: официальный календарь Туристической организации Суботицы (https://visitsubotica.rs/manifestacije/); мероприятия по окрестностям подписываем как таковые.
- Для Ниша, Крагуеваца, Зренянина и остальных городов пока предусмотрен собственный модерируемый JSON-файл data/afisha_events.json. Это **не** полный автоматический охват всей Сербии, региональные источники продолжают добавляться.

## Подключение Telegram
1. Создайте Telegram-канал с выбранным названием (например, «🇷🇸 Сербия 24 | Афиша»). Публичный адрес пока не занят и не подтверждён.
2. **Если вы переделали канал недвижимости в афишу, оставьте прежнего Telegram-бота** и предоставьте ему права администратора на публикацию.
3. Старый GitHub Secret **PROPERTY_BOT_TOKEN** автоматически используется новым сценарием, когда AFISHA_BOT_TOKEN не задан. Новый токен вводить не нужно, если старый безопасен и действует. Токен, ранее опубликованный в чате, рекомендуется заменить через @BotFather и обновить Secret.
4. Старую GitHub Variable **PROPERTY_CHAT_ID** также можно использовать автоматически, если она указывает на переделанный канал. Если она не настроена, создайте **AFISHA_CHAT_ID** с фактическим @username афиши либо числовым ID -100... . Не путайте название канала с его @username. Перед публикацией бот проверяет, что у канала в названии есть «Афиша», и что Telegram-бот может публиковать в нём.
5. GitHub → Actions → Serbia24 Afisha events → Run workflow запускает ручную проверку. Автоматическое расписание: ориентировочно 6 дневных проверок ежедневно в светлое время Белграда. GitHub может запускать их с задержками.
6. История опубликованных событий сохраняется в data/afisha_seen.json и никак не смешивается с новостным ботом.

## Добавление собственного события
В data/afisha_events.json — JSON-массив подтверждённых мероприятий. Пример структуры (это **только образец**, не фактический анонс):
```json
[
  {
    "approved": false,
    "url": "https://example.com/events/sample",
    "title": "Название события",
    "city": "Белград",
    "venue": "Место проведения",
    "start": "2026-11-21T17:00:00+01:00",
    "end": "2026-11-21T19:00:00+01:00",
    "category": "Выставка",
    "description": "Описание, подтверждённое источником",
    "price": "не указана"
  }
]
```
Замените URL и данные реальными фактами с официальной страницы события и включите approved=true только после проверки. Поле image пока не используется для копирования/публикации чужих изображений; превью создаётся по URL в Telegram.

## Ограничения
В первой версии парсер ожидает разметку schema.org/Event. Если страница организатора не содержит такую разметку или источник закрыт для автоматического чтения, событие безопасно пропускается; пустой канал лучше ошибочных объявлений. Все цены и даты могут меняться, поэтому у каждого поста есть ссылка на первоисточник с напоминанием перепроверить условия.

Цена проекта: GitHub Actions обычно может работать в бесплатных пределах для небольшого проекта; актуальные квоты GitHub и ограничения Telegram нужно учитывать. Интеграции с платными билетными API не используются.

## Переход с канала недвижимости

Автоматическое расписание недвижимого бота выключено, так как канал перепрофилирован в афишу. Его исходный код и возможность ручного запуска остались в репозитории. Для афиши используются существующие Secrets/Variables, а новый сценарий сперва проверяет Telegram-полномочия и название целевого канала без отправки сообщений. В GitHub Actions лог проверки явно покажет, хватает ли текущих настроек. Новостной канал «Сербия 24» не затрагивается.

## Редакционная политика: до 5 действительно интересных событий в день

С 13 ноября 2026 года публикации ограничены **не более пяти в календарные сутки по Белграду**, по **одному сообщению на проверку**. Расписание содержит 6 проверок в день: ориентировочно в 08, 10, 12, 15, 18, 20 часов зимой и 09, 11, 13, 16, 19, 21 час летом. Если ИИ одобрил только 1–2 достойных события, будет только 1–2 публикации; нижней обязательной квоты нет — лучше меньше публикаций, чем слабая афиша. История в data/afisha_seen.json учитывает уже опубликованные события и препятствует повторению.

Отбор состоит из двух этапов:
1. Алгоритм оценивает полезность: полноту описания, наличие места проведения и полноту фактов (неизвестная цена не снижает рейтинг), близость даты, культурную и семейную ценность, разнообразие тем. Давно идущие выставки с малым количеством сведений получают более низкий рейтинг.
2. ИИ-редактор получает *только проверенные текстовые данные источника* и решает, достаточно ли интересен анонс. Затем кратко переписывает название и описание на естественном русском. Дата, город, адрес, цена и ссылка не генерируются моделью — подставляются из исходной записи. Не допускаются придуманные числа и нечитабельный перевод. Сомнительное событие пропускается.

Поддерживаются уже используемые новостным ботом GitHub Secrets: GROQ_API_KEY (основной) и GEMINI_API_KEY/GOOGLE_API_KEY (резерв при техническом сбое). Новые платные сервисы для редактора не требуются. Когда оба ключа отсутствуют или редактура не прошла проверку, бот **не публикует** необработанные анонсы. При бесплатном тарифе Groq или Gemini могут действовать лимиты; если лимит исчерпан, публикации временно будут пропущены.

**Примечание:** ИИ улучшает русский стиль и помогает редакционному отбору, но не заменяет проверку фактов организатором. В каждом сообщении остаётся исходная ссылка на подробности; отдельная ссылка на билеты есть только при её наличии.

## События без опубликованной цены

Цена билета не является обязательным критерием интересности. Если официальная страница не сообщает стоимость, но анонс информативен и проходит ИИ-редактуру, публикация разрешена. Карточка показывает «🎟 Цена: не указана». **Нельзя писать «Бесплатно» без явного подтверждения**. Оценка интересности не снижает баллы только за отсутствие цены.

## Приоритет городов и ссылки

Большинство читателей интересуют Белград и Нови-Сад, поэтому при одинаковой ценности их события получат небольшой приоритет. Но действительно хорошие фестивали, ярмарки и необычные события в других городах могут попасть в подборку без географического запрета. Максимум — 5 материалов в сутки, ночью 22:00–08:00 публикаций нет.

«🔗 Подробности» ведёт на страницу описания/организатора. Отдельная строка «🎟 Купить билеты» появляется только при наличии подтверждённой специфической ссылки на продажу или бронирование. Если билеты только в кассе или ссылки нет, строка отсутствует. Для неуказанных цен остаётся «🎟 Цена: не указана».
