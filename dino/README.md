# DinoDvij — Telegram-бот для «Терианы и Диносьюты»

**Группа:** https://t.me/AVQ_GO

Отдельный модуль внутри репозитория «Сербия 24». Не меняет существующие боты. GitHub Actions проверяет источники раз в 15 минут.

## Что он делает

- Находит свежие новости по ключевым словам: терианы, террианы, диносьюты, квадробика, animal masks, therian и dinosuits.
- Отправляет в группу короткий заголовок, тематическую картинку и вопрос для обсуждения.
- Ссылка на публикацию скрыта за кликабельным символом «·» внизу сообщения. Когда требуется явное упоминание автора, оно должно оставаться видимым.
- При наличии Pixabay API Key иногда публикует лицензированные тематические видео непосредственно через Telegram sendVideo — они воспроизводятся в чате.
- Проверяет новости на повторы, отбрасывает старые заголовки и некоторые темы, связанные с насилием.
- Максимум **50 постов за сутки**, один пост за запуск; часы публикаций 08:00–22:59 (Europe/Moscow). Если подходящих материалов нет — пропускает публикацию.

## Подключение

1. **Важно:** если токен уже публиковался в чате, его необходимо отозвать через BotFather (Revoke) и получить новый.
2. Перейди в GitHub → репозиторий zamendirin-lgtm/serbia24-bot. → Settings → Secrets and variables → Actions → New repository secret.
3. Создай секрет **DINO_BOT_TOKEN** с новым токеном. Никому его не отправляй.
4. Чат уже определён автоматически: **-1002244148588**. Он задан в файле workflow, секрет DINO_CHAT_ID теперь не нужен.
5. Для фотографий и видео создай ключ на https://pixabay.com/api/docs/ и добавь его секретом **PIXABAY_API_KEY**. Это необязательно для текстовых новостных карточек, но нужно для настоящих медиа.
6. Проверь, что @DinoDvij_bot назначен администратором группы и может отправлять фото и видео.
7. Открой GitHub → Actions → DinoDvij — themed news and videos → Run workflow; сначала проверь с dry_run = true, затем с false.
8. Если push истории в workflow завершился ошибкой 403, в Settings → Actions → General → Workflow permissions выбери Read and write permissions.

## Охват и ограничения

Работают **Google News RSS и Pixabay**. TikTok, YouTube, VK, Reddit и Telegram-каналы **пока не подключены**. Чужие ролики оттуда нельзя автоматически перезаливать без прав. Для тематических картинок используется контент Pixabay либо CC0-фотографии Wikimedia Commons, если Pixabay API Key не задан; это иллюстрации, а не фотографии события. Автоматическая модерация не заменяет человеческую — особенно для сообщества с детьми.

История публикаций сохраняется в dino/state.json, код — в dino/bot.py, расписание — в .github/workflows/dino.yml.
