# DinoDvij — Telegram-видео для терриан и диносьютов

Группа: https://t.me/AVQ_GO

Бот ищет подходящие видеоролики про терриан, диносьютов, маски животных, квадробику и похожие костюмы. **Видео — единственный формат автоматических публикаций.** Фото, GIF, статьи, новости и случайные мультфильмы о динозаврах не публикуются.

## Видео и оформление

- Вертикальные 9:16 в приоритете.
- Горизонтальные 16:9 и другие пропорции **тоже допускаются**, если видео подходит по теме. Сохраняется исходное соотношение сторон: без обрезки, рамок и размытых полей.
- Для совместимости с Telegram ролики конвертируются в MP4 (максимум 18 секунд), отправляются через sendVideo и воспроизводятся прямо в чате.
- Подпись максимально короткая. Если лицензия требует указать автора и факт изменения, эта информация остаётся.
- Ссылка на исходную страницу оформлена компактной точкой «·», если правила лицензии это допускают.
- Защита от повторов, ограниченный список тем и исключение материалов с насилием/травлей.
- Проверка каждые 15 минут (GitHub Actions). До 50 видео за день, но **только если найдутся подходящие разрешённые ролики**. Время публикации: 08:00–23:59, Europe/Belgrade.

## Где ищет

Сейчас используется открытая библиотека видеороликов Wikimedia Commons с проверкой прав на повторное использование. Публикации из TikTok, YouTube, VK и других соцсетей не интегрированы: чужие видео нельзя автоматически перезаливать без разрешения. Гарантировать наличие достаточного числа подходящих роликов нельзя.

## Подключение и тест

1. Секрет **DINO_BOT_TOKEN** в GitHub Actions содержит новый токен BotFather (старый раскрытый токен должен быть отозван).
2. ID группы **-1002244148588** уже указан в расписании; бот должен быть её администратором.
3. Открой GitHub → Actions → **DinoDvij — themed videos (portrait + landscape)** → Run workflow. Для теста используй dry_run=true, для реальной отправки dry_run=false.
4. Если не сохраняется история публикаций, проверь Settings → Actions → General → Workflow permissions → Read and write permissions.

Файлы: dino/video_only.py — поиск и отправка видео; dino/bot.py — запуск и ограничения; dino/state.json — история; .github/workflows/dino.yml — расписание.

Обратите внимание: автоматический фильтр не гарантирует безопасность каждого файла; для чата с детьми необходима человеческая модерация.
