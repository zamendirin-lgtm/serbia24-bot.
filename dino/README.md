# DinoDvij — видео и оригинальные мемы для Telegram

Группа: https://t.me/AVQ_GO

## Развлекательный формат
- **Главные форматы:** смешные оригинальные картинки-мемы, видеоролики о террианах, диносьютах, квадробике и близких увлечениях.
- **Темы для обсуждения:** баттлы образов, «кринж или стиль», смешные неудачи с костюмами, блогерские дилеммы, противостояние трендов, выбор лучшего ролика.
- **Стиль:** ирония, острота, острые вопросы и лёгкие соперничества. Никаких фальшивых скандалов, персональных нападок, травли несовершеннолетних и выдуманных обвинений.
- **Мемы:** 30 собственных иллюстрированных карточек, без чужих фотографий и авторских мемов. Сохранение ID исключает повторы, пока выборка не исчерпана.
- **Видео:** Wikimedia Commons с проверенной лицензией. Вертикальные в приоритете, горизонтальные тоже разрешены, исходное соотношение сторон сохраняется. Если лицензия требует атрибуцию, даётся одна короткая строка.
- **Ссылки:** для оригинальных мемов не нужны, у видеоматериалов условия лицензий соблюдаются.

## Автоматизация
- GitHub Actions проверяет материалы раз в 15 минут, но реальная частота может быть ниже из-за задержек самого GitHub.
- Оригинальные мемы выходят в отдельные окна **09, 11, 13, 15, 18, 21** по Сербии; в остальное время ищутся тематические видео.
- **Жёсткого суточного лимита публикаций нет.** Частота ограничена фактическими запусками GitHub Actions, уникальностью материалов и ограничениями Telegram. Если нет подходящих роликов и новых мемов, бот пропускает выпуск.
- История размещений хранится в dino/state.json, группа — `-1002244148588`.
- `DINO_BOT_TOKEN` — секрет GitHub Actions; токен нельзя вставлять в исходный код.
- Самостоятельная загрузка из TikTok, YouTube, VK, Reddit пока не подключена, воспроизводимые ролики из них без прав не перезаливаются.

## Разговоры в группе
- Новый обработчик `dino/chat_replies.py` проверяет свежие сообщения каждые 5 минут по расписанию GitHub Actions. **Это не настоящий real-time сервер:** GitHub может запускать с задержками.
- Бот **сам иногда вмешивается в обычное обсуждение без упоминаний** (маски, диносьюты, тренды, мемы, споры), не чаще одного спонтанного вмешательства за 8 минут. Упоминания `@DinoDvij_bot` и команды `/roast`, `/battle`, `/help` тоже поддерживаются.
- На очевидные угрозы, сексуальные предложения и персональные оскорбления в чате бот реагирует коротким замечанием без травли участников.
- Характер теперь **дерзкий и немного грубый**: сарказм, «кринж», «ну нафиг», «хрень», резкие ответы на слабые аргументы. Личных оскорблений, дискриминации, травли и угроз подросткам нет.
- Подключён **локальный адаптивный движок `dino/learn_style.py`**, работающий без OpenAI или другого платного ИИ-API. Он в процессе общения подстраивается под частый безопасный сленг, длину сообщений, использование эмодзи и популярные темы.
- Это **не языковая нейросеть и не свободно генерирующий ИИ**: он продолжает использовать безопасные написанные заранее варианты ответов, но корректирует их стиль по накопленной обезличенной статистике. Для полноценного понимания произвольной переписки нужна локально развёрнутая LLM (потребует постоянного компьютера/сервера), либо внешний API.
- Для обучения используются только *агрегированные счётчики* из белого списка без текстов сообщений, имён, личных профилей и цитат. Статистика со временем затухает; обработка сообщений о бедах и травле исключается из обучения. Участникам группы следует сообщить, что бот анализирует сообщения для выбора ответов.
- `dino/chat_state.json` содержит технический курсор и обезличенные агрегированные счётчики стиля и типов сообщений. Тексты сообщений, никнеймы и ID пользователей в GitHub не сохраняются. Частота ответов на одного участника ограничена, чтобы не создавать спам.
- `.github/workflows/dino-chat.yml` — расписание проверок, `dino/test_chat.py` — тесты правил.

## Локальное обучение без платных нейросетей

- Файл `dino/offline_brain.py`: локальный классификатор намерений **Naive Bayes**, обучается при запуске на **112 оригинальных синтетических репликах** в 7 категориях: вопросы, споры, шутки, демонстрация творчества, мнения, приветствия, реакции.
- Используется для создания ответов из разных заранее проверенных безопасных вариантов с учётом типа последнего сообщения и темы. Не копирует текст участника в ответ.
- Файл `dino/learn_style.py`: на каждом запуске адаптирует частоты **категорий**, безопасного сленга, эмодзи, длины сообщений и темы по новому общению в чате. В GitHub попадают только агрегированные счётчики, без оригинальных сообщений и данных участников. Счётчики постепенно затухают.
- Реальные сообщения участников не сохраняются как тренировочные примеры и не направляются в сторонние сервисы. Этот движок — **не большая языковая модель**: он не способен самостоятельно придумывать произвольные тексты, как ChatGPT.
- Для работы не нужен OpenAI API Key или иные платные нейросетевые ключи. Задержки между ответами по-прежнему определяются GitHub Actions. Администратор должен сообщить участникам, что бот анализирует общие закономерности чата.

## Где лежит
- dino/memes.py — рендер оригинальных мемов и расписание юмора.
- dino/video_only.py — поиск разрешённых видеороликов.
- dino/bot.py — выбор контента, лимиты и доставка в Telegram.
- .github/workflows/dino.yml — автоматический запуск.
- .github/workflows/dino-meme.yml — разовая публикация для проверки.

**Примечание:** у чата есть подростковая аудитория, поэтому автоматический отбор не заменяет ручную модерацию. Острые дискуссии допускаются без личных оскорблений.
