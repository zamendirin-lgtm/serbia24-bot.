# DinoDvij — видео, короткие новости и беседы для Telegram

Группа: https://t.me/AVQ_GO

## Новая лента
- **Видео на первом месте**: короткие ролики загружаются в Telegram как MP4, вертикальные и горизонтальные пропорции сохраняются. Для слишком больших оригиналов Wikimedia используются реальные облегчённые версии. Один файл публикуется только один раз.
- **Короткие новости и разборы** о террианах, квадробике, диносьютах, масках и молодёжных трендах — только если новое подходящее видео не найдено. Автоматический поиск русскоязычных материалов через Bing News RSS; дополнительно — несколько проверенных редакционных разборов с **честной датировкой**, которые выходят однократно, а не выдаются за свежие события.
- Новостной пост содержит саму суть за 1–2 предложения, а не «читайте по ссылке». Ссылка на первоисточник дана маленькой точкой; большая кликабельная шапка больше не используется. Ставится тематическое фото с подходящей лицензией либо аватар группы. Если используется иллюстративное фото, об этом говорится; это **не фотография новости**, если её источник другой.
- Запрещено выдумывать новости, шокирующие «разоблачения» и факты про подростков. Не публикуем старое как «сегодня».
- Новости выходят с интервалом не менее 3 часов, если есть проверенный ещё не опубликованный материал. Нет материала — пропуск, не выдумка.
- Видео публикуются первыми. Полные сведения об авторстве и CC-лицензии размещаются в публичных карточках GitHub, в подписи только крошечный знак ⓘ. Для CC0 подписи об авторстве не требуется. Вертикальное и горизонтальное видео разрешено, пропорции сохраняются.
- Ранее использовавшиеся однотипные картинки «VS» **выключены как из автоматической ленты, так и из разовой публикации**. Новые мемы потребуют совершенно другого формата и отдельного контроля качества.
- Суточная квота публикаций не установлена, но дедупликация, интервалы и ограничения Telegram остаются. GitHub Actions запускает проверку по расписанию (приблизительно раз в 15 минут, возможно с задержками).

## Диалоги с участниками
- Бот не должен создавать вымышленные конфликты из обычных вопросов. Он может подключаться и к живым обсуждениям молодёжных трендов, мемов, питбайков и названий чата, включая отдельные публичные ветки ответов. Он не выдумывает факты о создателе или администрации группы. На угрозы людям и животным отвечает сдерживающим замечанием, а не пытается шутить о насилии.
- `dino/chat_replies.py`: настроен на проверку сообщений каждые 5 минут, но расписание GitHub Actions **может фактически запаздывать на десятки минут**. Бот собирает обезличенную статистику сообщений за последние 6 часов и может отвечать на сообщения моложе 45 минут, если они всё ещё уместны; спонтанные ответы ограничены паузой 3 минуты и 3 ответами на запуск. **Это не чат в реальном времени**: для быстрого постоянного диалога требуется непрерывно работающий сервер или процесс Telegram polling/webhook.
- `dino/offline_brain.py`: небольшой локальный классификатор Naive Bayes по семи типам сообщений, обученный на 112 синтетических примерах. Это **не полноценная языковая нейросеть**.
- `dino/learn_style.py`: счётчики обезличенных тематических предпочтений и безопасного сленга. Тексты участников, их имена и ID пользователей не сохраняются в репозитории.
- Стиль — дерзкий и ироничный, но без персональной травли подростков, угроз и дискриминации.

## Служебные данные
- `DINO_BOT_TOKEN` должен быть секретом GitHub Actions. Не вставляйте токен в код и сообщения.
- `dino/news_auto.py`: источники, проверка фактов, выбор разрешённых фото.
- `dino/video_only.py`: проверка лицензий и загрузка видео.
- `dino/bot.py`: ограничения и запуск.
- `dino/state.json`: дедупликация публикаций.
- `.github/workflows/dino.yml`: публикации.
- `.github/workflows/dino-chat.yml`: диалоги.

## Ограничения
RSS по узким темам часто не содержит достаточно новых достоверных материалов. После публикации нескольких подготовленных разборов могут появляться паузы. Автоматический генератор **не** должен заполнять пробелы выдуманными событиями, случайными костюмными картинками или одинаковыми вопросами.
